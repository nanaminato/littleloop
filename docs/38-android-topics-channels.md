# Android 群话题与频道

从群聊进入「群话题」，可以创建话题、查看各自的未读数和历史。每个话题通过现有 `parentId` 关联父群，消息和已读位置仍按独立会话保存。打开话题列表不会把被覆盖的聊天视图算作已读，打开某个话题后才同步它的已读位置。话题通知沿用账号的群聊通知设置。

从聊天列表进入「频道」目录，可按名称查找、订阅、取消订阅及打开频道，也可新建自己发布的频道。新订阅可以查看已有广播，订阅前的历史不新增未读。Android 根据服务端的 `canPost` 决定是否显示输入框，发送接口仍检查发布权限。频道有独立的通知开关，可与网页版账户设置同步。

使用原有的 `/channels`、`/channels/{room}/subscription`、`/rooms/{parent}/topics`、消息和已读接口。新消息继续通过 SignalR 更新 Android 和网页版，并沿用原生 FCM 与浏览器通知。目录在联网时刷新，已加载的会话与历史继续使用本地缓存。

## 实测

在 Android 17 模拟器、Chrome、真实 MySQL 和真实 FCM 上，分别从 Android 与 Chrome 创建同一群的两个话题。父群和两个话题的历史彼此独立。网页版发布话题消息时，Chrome 应用内提示与 Android 后台通知同时出现，未读只增加在目标话题。Android 打开该话题后，同一账号在网页版的已读位置同步。非群成员创建话题或直接请求话题历史均返回 `404`。

Android 订阅网页版创建的频道后可查看已有广播，旧历史没有新增未读。网页发布新广播后，Chrome 与 Android 都提示新消息，Android 阅读后网页版同步已读。普通订阅者在 Android 没有输入框，直接发送请求返回 `403`，未订阅账号直接访问频道历史返回 `404`。Android 创建频道并以发布者身份发文，保持频道打开的网页订阅者实时收到。Android 构建和 Lint 均通过。本机验收记录位于 `data/chat-android-spaces/`。
