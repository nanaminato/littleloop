# Android LittleLoop 机器人卡片

已授权操作员可以在支持的私聊或群聊中接入机器人。点「引用源码提问」，从宿主列出的授权文件中选一项，填写行号与问题。引用记录包含路径、行号、SHA-256 和当时的源码。对已有消息点「安排任务」，填写开发目标及验收要求，原消息作为任务上下文。

点击「源码问答」「源码引用」或「开发任务」卡片可查看详情。任务运行时，Android 与网页版从同一服务端工作记录刷新状态。审批人可查看待处理请求的参数并选择「允许本次」或「拒绝」。服务端会再次检查会话、角色及请求 nonce。工作详情提供服务端允许该账号读取的补丁、命令退出码和测试输出。

本地缓存保留消息卡片和引用快照。提交问答、任务与审批，以及读取最新状态和执行证据需要联网。Android 通过同一个聊天会话调用现有机器人接口。

## 验收

在 Android 17 模拟器、Chrome 和真实 MySQL 上，操作员从 Android 引用 RelaxKonOS 的 `ApplicationDescriptor.cs` 第 1–20 行提问，网页版收到 LittleLoop 回答。操作员再从群内已有消息安排开发任务。任务仅在隔离副本中加一行验收注释。

审批人从 Android 批准补丁，从 Chrome 批准 `appid-tests`。两个客户端看到同一任务的审批与完成状态，Android 展开并查看了补丁和测试输出。操作员在 Android 没有审批按钮，操作员和普通成员直接请求审批均返回 `403`。两枚已消费的审批标识重复提交均返回 `409`，最终只有一个文件补丁和一次测试回执，19 项测试通过，退出码为 0。APK 构建和 Android Lint 均通过。本机验收记录位于 `data/chat-android-bot/`。
