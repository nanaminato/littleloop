# 感知、语言与知识

## 持续视觉流

视觉不是孤立图片识别：帧 → 色彩/轮廓/区域候选 → 物体候选 → 跨帧轨迹 → 场景事件 → 记忆关联。保持同一物体的身份假设，处理遮挡、离开后重现、外观变化和多个相似物体；记录 ID 切换率与误匹配率。

允许先用简单传统算法与规则，后续通过接口接入更复杂的识别器。基于逻辑的主动描绘定义为：从内部场景图生成可检查的草图/布局假设，再与实际观察对照；不把生成画面当作真实观测。

## 听觉与语音

音频输入 → 多声道分离/方向估计（可选）→ 短暂缓冲 → 声学事件/语言候选 → 基础语义 → 充分语义解析 → 知识/记忆。

支持分级识别：
- 短片段语言粗分类，例如中文、日文、韩文，允许“无法判断”。
- 基础语音语义识别：关键词、说话意图、实体候选。
- 充分语义识别：句法、语境、指代、歧义与行动约束。

不得将短歌片段的语言分类视为必然准确；歌曲、混合语言和背景声都可能造成误判。

## 触觉与其他感觉

先统一为时间戳、强度、位置、来源、置信度等事件；将温度、压力、接触、运动等作为可选输入。感觉融合形成可修正的世界状态，而非直接假定感知为真。

## 语言与语义

区分文字形式、语言解析、内部概念、关系图和外部表达。研究基于汉语的逻辑体系、补充汉语体系及汉语转义逻辑，但内部表示应能承载多语言概念，避免将汉语语序直接等同普遍逻辑。

研究方向：
1. 汉语的省略、语境、量词、时间体貌与歧义消解。
2. 补充的结构化表达：实体、谓词、范围、条件、否定、置信度与来源。
3. 中文/日文/英文等跨语言概念映射，允许不完全对齐。
4. 语言学习：从示例、反馈和上下文更新词义与规则。
5. 语言体系设计：在表达力、歧义、可学习性、可验证性之间权衡。

## 知识

概念、属性、关系、规则、范式、例外、证据和版本。知识预填充/迁移/导入必须标注来源、许可证、格式、可信度及适用范围；导入不等于相信。支持语义关联、类比映射、规则冲突检测与人工纠错。
