# Android 消息长按菜单

长按消息气泡可编辑、删除、转发、置顶消息或添加到个人收藏。编辑和删除仅对本人发出的普通消息开放。服务端继续用会话成员资格、发送者和消息类型做权限检查，不能通过直接请求修改别人的消息。转发使用现有服务端复制逻辑，保留转发来源及可转发的附件。收藏写到当前账号的私人会话，可从会话列表顶部的「收藏」进入。

消息置顶和原有的会话置顶是独立设置。每个会话有一条共享置顶消息，Android 和网页版都会显示入口，点击可定位到该消息。支持发言的会话成员可设置或取消；频道仅发布者可操作。置顶已删除的消息会被拒绝，删除当前置顶消息会在同一事务中清除置顶。

网页版与 Android 共用 API 及 SignalR 更新。Android 看到历史版本变更时会刷新当前已加载的消息范围，已定位的旧历史窗口也能反映修改和删除。消息操作需要联网；离线仍可阅读已缓存的历史。

## 实测

在 Android 17 模拟器、Chrome 和真实 MySQL 上，编辑和删除均完成双向同步。Android 转发后网页版在目标群看到副本及原发送者，个人收藏只对收藏者可见。Android 置顶、Chrome 取消置顶以及删除置顶消息后的自动清除均同步到另一端。

普通成员长按他人的消息时没有编辑和删除选项，直接调用两个接口均返回 `404`，原消息保留。Android Debug 构建、Lint、Angular 和 .NET 构建通过。本机验收记录位于 `data/chat-android-actions/`。
