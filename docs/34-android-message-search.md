# Android 消息搜索

在会话列表点「搜索消息」搜索所有可访问会话，或从会话顶部进入「搜索」限定到当前会话。匹配正文及附件名。已删除消息不参与搜索。

联网时复用网页版的 MySQL 搜索，查询覆盖完整历史，每次返回最多 50 条。Android 可点击「更多结果」。网页版省略分页参数时继续获取首页。用户只会收到自己有权访问的会话结果。

断网时退回当前登录会话的 SQLite 缓存，界面标注「离线 · 仅搜索本机缓存」。搜索仅覆盖缓存中最近同步过的会话，以及每个已访问会话保存的最近 50 条消息。服务器明确返回访问拒绝时，客户端不会返回缓存作为替代。重新连上后可点「重新搜索」，查询完整历史。

点击结果时，使用原会话及消息序号直接请求目标前后的历史页并高亮定位。历史视图与最新消息分开，定位旧消息不会从旧位置一路补拉到最新，也不会改动服务器上的已读位置。点击「回到最新」恢复实时聊天。离线时可以定位缓存中的原消息。

## 实测

使用 Android 17 模拟器、Chrome 和真实 MySQL。在含 67 条消息的群中，Android 和网页版均通过搜索定位到第 1 条，Android 返回最新后能看到第 67 条。同一关键字的服务端全局结果分两页，会话内搜索排除了另一群的匹配。断网并强制停止 Android 后，重开可找到和定位缓存中的新消息，超出缓存窗口的旧消息查不到。

使用第三个账号在 Chrome 和 Android 均搜索不到该群消息。会话内搜索接口也没有返回受限结果，直接请求该群历史返回 `404`。Android Debug 构建、Lint 和 .NET 构建均通过。验收截图与结果位于本机 `data/chat-android-search/`。
