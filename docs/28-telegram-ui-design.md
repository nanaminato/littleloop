# Telegram 式聊天界面设计

状态：设计稿。适配现有 [阶段 A 至 D](23-chat-platform-design.md) 的 Angular 聊天应用。打开 [可点击原型](design/chat-ui.html) 可切换桌面、手机及各设置分类。原型使用示例数据。

## 参考与范围

桌面以 Telegram Desktop 的双栏会话界面为基准。移动以 Telegram Android 的会话列表、抽屉及分层设置为基准。保留圆形头像、蓝色强调、紧凑列表、双侧消息气泡、菜单位置和导航层级。品牌、头像和背景使用本项目自己的素材。设置按常用任务分类，具体项及状态见下表。参考 [Telegram 官方 FAQ](https://telegram.org/faq)、[官方设置界面](https://translations.telegram.org/screenshots/8383/settings/) 和 [Telegram Desktop 源码](https://github.com/telegramdesktop/tdesktop/blob/dev/Telegram/SourceFiles/mainwidget.cpp)。

| 场景 | 桌面 | 手机 |
| --- | --- | --- |
| 会话 | 左栏 320–360 px，顶部菜单按钮和搜索，底部为会话列表。中栏铺满剩余空间 | 顶部菜单、标题与搜索，列表占满屏幕，右下角新建消息 |
| 消息 | 顶栏头像、名称、搜索、更多。时间线独立滚动，底部固定输入栏 | 单页会话，返回恢复列表滚动。输入栏随软键盘上移 |
| 详情 | 点击头像打开右侧详情，宽约 300 px。窄窗口切换为独立页 | 点击头像进入详情页；返回保持时间线位置 |
| 设置 | 主菜单打开设置面板，分类进入子页，返回上一级 | 抽屉进入全屏设置；顶栏返回，保留上一级滚动 |
| 搜索 | 主搜索显示会话与消息分组，顶栏搜索限定当前会话 | 进入搜索模式，选结果定位消息，返回恢复结果和搜索词 |

## 页面与交互

- **会话列表**：已归档与文件夹在列表上方。行包含头像、名称、时间、末条消息摘要、未读计数与静音状态。置顶会话优先。桌面右键和手机长按共用操作菜单。
- **消息时间线**：日期分隔，自己在右、对方在左。同一发送者连续消息合组。气泡显示回复、时间和发送状态。发送失败在原位重试。向上分页保持可见消息锚点；记录有跳转目标时按消息 ID 定位。
- **输入与消息操作**：附件在输入框左侧，发送在右侧。回复、编辑在输入框上方显示可取消的上下文条。消息菜单依权限显示回复、复制、转发、收藏、编辑、删除。桌面快捷键与触屏菜单保持可替代。
- **群、话题和频道**：详情展示群成员、话题入口、共享媒体与通知。话题列表保留所属群导航。未订阅频道在详情展示订阅，订阅后页底显示通知操作；有发布权限时出现输入框。
- **机器人**：机器人保留独立头像与身份。源码引用从附件或消息动作进入；任务与审批采用气泡内卡片。点击卡片才查看补丁或测试详情，返回保持时间线。授权参数和审批按钮只向授权者显示。设置中的「集成」负责安装说明，不提供绕过项目授权的开关。

## 设置树

账户摘要始终位于设置首页顶部，头像、显示名和用户名可从「编辑资料」进入。行尾显示当前值、开关或进入箭头。危险操作单独分组。下列「需实现」是设计范围，接到实际读写后再对用户开放。

| 一级分类 | 二级设置 | 当前可复用或需实现 |
| --- | --- | --- |
| 编辑资料 | 头像、显示名、用户名、个人简介 | 复用用户名；资料字段、头像上传与修改需实现 |
| 通知和声音 | 私聊、群聊、频道；提示预览、声音；静音清单与例外 | 复用会话静音及应用内通知；分类偏好与声音需实现 |
| 隐私和安全 | 修改密码、会话可见性、群邀请权限、已屏蔽用户 | 复用登录及会话鉴权；独立设置需后端支持 |
| 设备 | 当前会话、其他会话、退出指定设备、结束其他会话 | 现有 Cookie 登录；设备清单与远程撤销需实现 |
| 聊天设置／外观 | 系统／浅色／深色，强调色、背景、字号、发送键、动画 | 设计为即时预览；设备偏好本地保存 |
| 数据和存储 | 图片自动加载、文件下载、缓存使用与清理 | 复用鉴权下载；下载偏好和缓存管理需实现 |
| 聊天文件夹 | 新建、排序、包含／排除会话、按会话类型筛选 | 复用现有会话分类与归档；文件夹需跨设备同步 |
| 语言 | 简体中文、English、跟随系统 | 界面文案字典和语言切换需实现 |
| 集成 | 已启用机器人、作用范围、操作员与审批权限说明 | 复用现有机器人安装与权限边界 |
| 高级与关于 | 键盘快捷键、版本、使用帮助、退出登录 | 复用退出；添加键盘说明及版本信息 |

个人资料、通知例外、隐私规则、文件夹与设备清单由服务端持久化。主题、字号、输入键习惯等按设备保存。加载失败保留最近一次确认值，写入失败显示重试。浏览器通知权限和账户通知偏好各自呈现。关闭网页后收到推送需要另行接入 Web Push。Telegram 的通话、秘密聊天和付费设置需要对应服务能力后再设计入口。

## 设计令牌和验收顺序

- 浅色基调为白色双栏、浅蓝选中行、淡青聊天背景、蓝色操作和白／浅绿消息气泡。暗色使用同一层次的深色令牌。文字保持系统字体及高对比，移动触控目标至少 44 px。图标配可读标签及键盘焦点。
- 第一批实现桌面和手机外壳、会话列表、消息气泡、输入条、菜单和详情，保留现有实时、未读、历史、附件与权限回归覆盖。
- 第二批实现设置首页及可持久化的外观、通知、语言和会话文件夹。补齐账户、隐私和设备的后端契约，再开放对应操作。
- 第三批校验群话题、频道订阅、机器人审批和详情抽屉。桌面检查 1440 和 1024 px，手机检查 390 和 360 px。在真实浏览器与 MySQL 做双账号验证，覆盖返回恢复、长消息无溢出、菜单键盘访问、设置重启恢复，以及另一账号看不到审批细节。
