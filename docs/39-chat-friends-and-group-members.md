# 好友申请和群成员管理

网页版在主菜单提供「好友」。Android 在会话列表提供同名入口。输入对方用户名即可发送申请。收件人可接受或拒绝，申请人可查看待处理状态。好友列表可打开两人已有的私聊，也可创建私聊。

新群的创建者自动成为群主。网页版从会话头像打开会话详情，Android 从群聊进入「群成员」。群主可按用户名邀请成员、移除成员，或把群主转让给现有成员。普通成员可查看成员列表。邀请遵守接收方的群邀请设置和双方的屏蔽规则。转让后，原群主仍是成员。

好友关系按稳定的账号 ID 保存。群成员变更在一个 MySQL 事务中同步到群聊和已有话题。移除成员保留其已发送的消息，并撤销其对群聊及话题的访问。SignalR 通知在线客户端重新读取当前关系和权限。Android 在获得最新成员权限后清除已撤权会话的历史缓存。

旧群的数据没有可靠的创建者记录。此升级保留其成员和消息，旧群的群主仍待明确指定。

## 验收

在 Android 17 模拟器、真实 Chrome 和现有 MySQL 上用三个测试账号完成验收。

- Android 发起好友申请，Chrome 接受，双方从好友列表打开私聊。Android 拒绝另一条申请后，Chrome 的待处理记录实时消失。服务重启后，已接受的好友关系仍可读。
- Chrome 邀请成员、转让群主，Android 群成员列表和操作权限随即更新。普通成员尝试邀请、移除和转让均收到 HTTP 403，原群主在转让后也收到 HTTP 403。
- Android 新群主指定并移除成员，Chrome 中被移除的账号退出正在查看的话题。群聊和话题的会话列表均移除对应条目，读取历史、读取成员列表和发送消息均收到 HTTP 404。其原有消息仍可由群成员读取。
- .NET、Angular、Android 构建和 Android lint 均通过。
