# 记忆、存储与注意力

## 分层记忆

1. **mini 临时存储**：当前感知帧、即时计算、短暂候选；容量和 TTL 严格受限。
2. **工作记忆**：当前目标、对象轨迹、活跃假设、近期事件。
3. **未处理缓冲区**：原始输入与待巩固事件，异步交给非主认知循环处理；断电恢复与隐私策略独立定义。
4. **情景记忆**：何时、何地、发生了什么、主体如何行动及结果。
5. **语义记忆**：概念、关系、规则、知识来源和冲突。
6. **程序记忆**：动作序列、技能、适用条件与成功率。
7. **元记忆**：知道自己知道什么、不知道什么，以及记忆的可靠程度。

## 基于关注度的多向记忆

节点之间支持时间、空间、对象、语义、因果候选、情绪权重、共同出现、任务关联等多种边。边有方向、权重、来源、证据、时间和置信度；相关不等于因果。检索支持从对象、感觉、语句、目标、场景等多个入口展开。

关注度由新奇性、当前任务、重复出现、显著性、反馈价值和用户授权的长期兴趣共同决定。注意力影响写入优先级与检索预算，但不能替代事实证据。

## 模糊与遗忘

允许近似匹配和不完整回忆，但输出须标识确定事实、推断、猜测与未知。记忆强度随时间、使用频率、冲突和价值变化；先降低检索优先级，再考虑压缩/合并/删除。保留高价值知识的来源和纠错历史。敏感数据须支持明确删除，不应被“自动遗忘”替代。

## 自动整理

后台执行去重、索引重建、语义归并、冲突检测、巩固和归档。主循环只提交事件；后台结果通过版本检查合并，避免异步覆盖较新认知状态。

## 待验证实验

- 一次性快速浏览材料后，在提示线索下能否找回部分内容，与完全未浏览基线比较。
- 多次弱关联经历是否能提升延迟检索成功率。
- 对象更名或外观变化后是否保持同一实体关联。
- 遗忘策略能否在有限存储预算内保持任务成功率。
- 错误记忆能否被新证据纠正，而非不断强化。

评价指标：召回率、误关联率、检索延迟、存储占用、来源正确率、遗忘后的任务表现。
