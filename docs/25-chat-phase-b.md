# 阶段 B · 日常聊天

启动方式沿用 [阶段 A](24-chat-phase-a.md)。阶段 B 服务启动时在现有 MySQL 上增量建表、加列。已有账号、会话、消息序号和已读游标继续使用。

- **图片和文件**。每条消息可带一个最多 5 MiB 的附件，支持仅发附件。PNG、JPEG、GIF、WebP 在对话中预览，普通文件下载。此阶段将小文件内容与元数据放在 MySQL；后续独立附件存储可沿用同一鉴权下载接口。读取权限由引用该附件的消息及当前会话成员决定。
- **搜索**。搜索本人所有会话的正文和附件名，最多返回 50 条。点击结果打开会话，定位到相应消息；已删除内容不返回。
- **编辑和删除**。发送者可以编辑正文或删除自己的消息，其他成员通过实时更新看到结果。删除保留占位和序号，原消息的附件链接失效。旧版本留在服务端版本表。已经转发的消息是独立快照。
- **转发与个人收藏**。从消息菜单选择目标会话，或存到个人收藏。转发要求能访问源消息且是目标会话成员。目标会话只收到被转发消息的内容。收藏只有账号本人能读取。
- **置顶、归档和静音**。三个设置按账号与会话保存，同一账号的设备共享。静音停止该会话的应用内新消息提示，未读计数照常更新。当前通知在打开的网页内显示。
- **移动端**。窄屏下会话列表和消息页分别显示，返回列表后可搜索、打开归档和收藏。

## 浏览器验收

2026-11-15，Chrome 与 MySQL 8.4.13 实测：

1. 在已有阶段 A 记录的数据库上升级，原有账号及聊天历史可读。
2. 同一账号在桌面和 390 像素手机视口同时登录，手机打开消息后桌面未读实时清除。手机操作置顶、归档和静音，桌面同步对应状态。
3. 手机上预览图片并下载文件，下载字节与原文一致；非成员知道消息位置也无法下载。删除原消息后原下载链接失效，已经授权转发的副本仍可下载。
4. 编辑和删除在两端同步，搜索返回改后的正文，删除后不返回。非成员搜索无结果。转发到私聊和个人收藏都通过，其他人无法读取收藏。
5. 静音会话仍产生未读，当前网页不弹出该会话通知。手机从消息页返回、打开归档、取消归档并重新进入会话，无横向溢出。
