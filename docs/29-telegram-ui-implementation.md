# Telegram 式聊天界面实施

当前聊天应用已使用 [Telegram 式界面设计](28-telegram-ui-design.md) 的布局。入口仍为 http://127.0.0.1:5190/chat。

- 桌面使用会话列表和聊天双栏，详情按需展开。窄屏切换为列表、聊天、详情逐屏导航。会话行显示头像、末条消息摘要、时间、未读和静音状态。
- 时间线使用两侧消息气泡、日期、已发送标识和消息操作菜单。会话切换保留草稿和滚动位置，历史分页保留视口。附件、回复、搜索、群话题、频道和 LittleLoop 审批沿用原有服务。
- 设置有十个入口。资料支持头像、显示名和简介。通知按私聊、群话题和频道配置，可关闭预览、应用内声音或对单会话静音。隐私支持拒绝新群邀请和修改密码。设备页能撤销单个或全部其他设备。
- 文件夹支持类型、包含和排除、排序。资料、通知、隐私、文件夹和设备会话存入 MySQL。主题、强调色、背景、文字大小、发送键、图片预览和语言按浏览器保存。

## 升级边界

后台在启动时为现有 MySQL 增量建表；已有消息、历史任务及权限沿用。旧登录 Cookie 没有设备标识，升级后需要重新登录一次。图片头像仅本人和可见会话中的其他成员能读取；频道头像可见性限发布者。文字消息的时间戳从本次升级后记录，旧消息仍显示原历史顺序。

此版本之后补齐了用户名修改、屏蔽名单、中英文界面与 Web Push。见 [Telegram 式设置补齐](30-telegram-settings.md)。

## 真人浏览器验收

使用 Chrome 与现有 MySQL 8.4.13，1440、1024、390 和 360 像素视口实测。验证桌面与移动导航、长消息无横向溢出、主题与语言恢复、双设备资料和文件夹同步、关闭通知仍更新未读、附件、源码引用、群话题、权限和设备撤销。头像可加载，陌生账号无法读取；临时账号修改密码后旧密码及其他设备会话失效。

真实 RelaxKonOS 隔离任务在新版话题内完成。审批账号从气泡卡三次批准，发起人读取不到审批参数且提交返回 403。基线失败后修复并通过 19 项回归。服务重启后，MySQL 设置、聊天历史和已完成任务均可重新打开。

本机验收记录与截图位于 Git 忽略的 data/chat-ui-implementation。
