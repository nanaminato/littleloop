# Android 会话列表与新建会话重构

2026-11-15，依据用户明确要求，沿用[会话与频道管理](44-android-conversation-refactor.md)和[好友与群成员管理](45-android-social-refactor.md)的组件、状态和共享权限拆分方式。范围包括首页会话列表、频道目录以及私聊、群聊、频道、群话题创建表单。Repository、服务端接口、成员同步和消息协议保持不变；群话题与频道的领域行为继续遵循[现有设计](38-android-topics-channels.md)。

展示组件不调用 Repository。控制器复用现有的请求、忙碌状态、错误与实时刷新机制。会话列表保持服务端顺序、归档过滤及大小写不敏感的名称搜索；话题仍仅在输入搜索词时出现在首页，群内话题列表只显示所属群的未归档话题。

## 行为与权限

- 群聊只要求群名称，成员仍可留空，创建后可邀请；私聊要求对方账号。切换私聊／群聊不清空已输入的名称和成员。
- 私聊、群聊、频道、话题的提交共用登录、联网和忙碌状态规则。离线时可打开表单、保留草稿，但不能发起无法完成的创建请求。
- 创建话题依据当前父群成员资格，不能误用 `canPost`、`canManage` 或管理员权限。群主、管理员、普通成员和禁言成员均保留现有创建资格；提交时再次检查父群是否仍存在于当前账号的群列表中。
- 频道发布者不显示取消订阅；只有已订阅频道可打开。组件和提交控制器使用相同规则，提交时重新读取频道状态。
- 搜索草稿按账号保存，创建草稿按账号、表单入口（私聊／群聊、频道、话题）和父群隔离；旋转保留输入，取消关闭后重新打开是新表单。服务端失败保留草稿，成功后沿用原导航关闭表单并打开会话。

上述规则属于客户端入口控制，服务端继续负责最终授权。
