# 学习、推理、驱动与自评估

## 学习层次

- **一次学习**：从单次事件建立暂定记忆。
- **重复学习**：通过反馈调整权重、规则和技能。
- **动作学习**：学习前提 → 动作 → 结果的可重现过程。
- **二次学习/元学习**：评估学习策略本身，调整复习、检索、探索和验证方式。
- **知识迁移**：将已有概念、范式或技能映射到新情境，明确适用条件。
- **知识传递**：以可解释的规则、实例、过程和证据导出，再由其他主体校验导入。
- **重现**：在相同初始快照、输入和随机种子下重放决策。

## 推理与直觉

显式规则/逻辑负责可验证推导；相似性与类比负责产生候选；启发式“直觉”负责快速粗估，最终需结合证据和预算验证。不同推理路径保留来源、置信度、矛盾与失败记录。不可将概率或相似度直接伪装成逻辑必然性。

## 驱动力

三类目标来源：
1. **指令驱动**：明确的用户目标及边界。
2. **身份/角色驱动**：持久但可编辑的职责、价值约束和行为偏好。
3. **模拟自由驱动**：在授权范围内基于好奇心、知识缺口和任务价值选择探索目标。

驱动力不赋予系统绕过用户权限、自行联网传播数据或无限消耗资源的权利。

## 情感、兴趣与关注度

用内部状态表示新奇、挫折、完成感、风险、兴趣等调节量，观察它们是否改善任务选择、记忆与学习；不声称系统有主观情绪体验。兴趣与关注度可学习，但应有衰减、重置与用户控制。

## 自评估

学习评估：预测与实际差异、保持率、迁移成功率、置信度校准、学习成本。行动评估：目标完成、代价、风险、可逆性、用户反馈和副作用。区分即时奖励与长期效果，避免系统只优化容易刷高的内部评分。

## 机器人伦理与行动安全

能力权限最小化；默认只读/模拟；高风险或不可逆行动需明确授权；操作留痕、可中断、可回滚；个人数据最小化、可删除；禁止将自我保存或无限自我扩张设为无条件最高目标。安全约束独立于可学习策略，防止自我修改绕过。

## 核心开放问题

如何区分真正的概念泛化与记忆匹配？如何防止错误知识自我强化？如何定义可检验的“理解”？何时应放弃一个规则、模块或目标？如何证明自驱动在资源和权限边界内稳定？
