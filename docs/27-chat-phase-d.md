# 阶段 D · 机器人适配、群话题和频道

沿用 [多人聊天](24-chat-phase-a.md) 与 [机器人配置](26-chat-phase-c.md)。启动时在原有 MySQL 表上补充话题归属、频道所有者和适配器任务结果字段。

## 两种机器人

LittleLoop 与「源码审阅」共用会话安装、源码问答、任务创建、任务状态和卡片。操作员可分别打开机器人私聊，也能把两种机器人加入同一个群或话题。此前已安装 LittleLoop 的群可用「更新机器人」启用第二种适配器。

LittleLoop 能按配置的项目边界执行，经审批运行固定命令和修改允许的源码。源码审阅直接使用被冻结的引用，报告行范围、哈希、非空行数和带行号摘录，适合核对分享的代码片段。它不调用外部模型，不执行命令或修改文件，也没有审批能力。任务从带源码引用的消息发起，报告与状态一同保存到 MySQL。既有 LittleLoop 任务和旧工作台记录采用原适配器，在升级后可继续打开。

## 群话题和频道

- 群成员可以创建话题。话题从所属群继承当前人员范围，拥有独立时间线、回复、未读和通知。可从群顶栏打开话题，也可从话题返回群。当前群成员在建群时确定。
- 已登录用户可在频道目录发现频道名称，订阅后才能读取频道广播和历史。订阅时旧历史可读，新广播计入未读。取消订阅后，历史、实时广播和通知访问随订阅一同结束。
- 每个频道由创建者发布消息。订阅者可读、搜索、标记已读、静音和取消订阅。直接调用发布或转发到频道的接口也会验证所有者权限。
- 群话题和频道沿用现有 SignalR 通知和 MySQL 历史。通知在网页内显示，静音和已读逻辑与群聊相同。


## 浏览器验收

2026-11-15，使用 MySQL 8.4.13 与三个独立 Chrome 账号实测：

- 两个群话题各自有历史，群主时间线也独立。群外账号无法读写话题或创建话题，SignalR 未向其发送相关事件。
- 发布者可广播。订阅者读到历史和实时广播通知，但不能直接发送或转发到频道。未订阅账号没有历史和实时事件。取消订阅后不再收到广播，另一台已打开频道的设备也会关闭频道，重新读取返回 404。
- 两种机器人在同一话题用相同问答、安排与状态接口。源码审阅任务 d850ea7b-2566-421f-9ede-1242c19733fe 返回哈希与带行号摘录，审批接口拒绝操作。LittleLoop 任务 e01f2477-8256-493d-8fc7-2e59a42b43ae 在隔离的 RelaxKonOS 副本实际运行。基线失败后，一处补丁和复测通过 19 项。
- 重启聊天服务后，两项机器人任务、独立话题历史及取消订阅状态仍可验证。旧工作台导入保持幂等。

本机证据在 Git 忽略的 data/chat-phase-d 下，包括 robots.png、restart.png 和 result.json。
