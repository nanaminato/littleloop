# 总体概念与研究问题

## 目标

探索一种“慢 AI”：在有限计算资源下，通过事件驱动、规则、记忆、工具和反思完成持续认知。处理可以慢于人类；重要的是新经历能够改变未来行为，而非仅在上下文中短暂保留。

## 核心假设（均需验证）

1. 显式关联记忆与检索机制能够支持部分长期学习和迁移。
2. 注意力、兴趣和任务目标可调节记忆写入、检索和遗忘。
3. 可组合规则、范式、类比和相似性判断能解决有限领域的推理问题。
4. 感知中的对象连续性能够支持跨时间识别“同一个物体”。
5. 反思、失败反馈和二次学习能改进策略及学习方式本身。
6. CPU 上的低成本模块可以实现部分有用认知行为，但不意味着自然产生人类意识或完整通用智能。

## 概念区分

- **识别**：对输入形成候选类别、对象或事件。
- **理解**：形成可验证的关系、约束和可用于预测的内部模型。
- **感觉/直觉**：可作为低计算成本的启发式估计与置信度信号；不宣称具有主观体验。
- **情感**：初期定义为影响优先级、记忆强度、探索倾向的内部状态变量。
- **知识**：可溯源的概念、事实、规则、过程与关系。
- **记忆**：包含经历、来源、时间、置信度及可遗忘的关联网络。
- **自驱动**：在授权目标与安全边界内自主选择下一步任务。
- **人类式逻辑合理理解**：作为比较和评价目标，而非已具备能力。

## 不作为初期承诺

不承诺自主意识、无监督自我改写生产代码、完美多模态识别、完全可靠的逻辑或无需数据的自然语言理解。

## 研究方法

以小型可复现实验为中心；每个实验记录假设、样本、基线、指标、结果和反例。保留失败案例，避免用演示效果替代评估。
